## Plan

1. Recruit 5 people from the primary audience (charter § Users).
2. 15-minute interview each. Ask about the problem, not about the solution.
3. Record each interview with the template below on the same day.
4. After 5 interviews, write at least 3 patterns with supporting quotes.

## Interview script (problem-focused)

1. Tell me about the last software project you planned. What tools did you use?
2. How did you know a phase was really finished?
3. Tell me about a time work started before something it depended on was ready. What happened?
4. Who checked the work? How?
5. What do you do today when a spreadsheet status is wrong?
