# docs/drive — espelho da pasta do Drive do cliente

Gerado por `npm run docs:pull -w @clients/prj-01-cleansea`. **Não edite estes arquivos à mão**: a próxima sincronização sobrescreve.

- Google Docs → Markdown (exportado pela API do Drive, via ABAP).
- Planilhas, PDFs e outros arquivos → listados em `_manifest.json` com o link, sem conteúdo.
- Cada arquivo traz no topo: ID do arquivo no Drive, data de modificação e link.

Para mudar um documento: edite no Google Drive (ou peça ao ABAP para publicar uma versão), depois rode a sincronização de novo.
